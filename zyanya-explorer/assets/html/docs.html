Zyanya Protocol Specification

A formal technical overview of AstroBWTv3 proof-of-work, GhostDAG k=18 consensus, pure IPv6 transport, and the ZCL Virtual Machine.

1. Abstract & Cypherpunk Thesis

Traditional blockchains suffer from dual centralizations: mining hardware captured by ASIC cartels, and network topology constrained by NAT traversal and IPv4 exhaustion. Furthermore, existing smart contract platforms were designed for human interactive wallets, creating friction for autonomous AI agents.

Zyanya solves this by fusing three sovereign primitives: AstroBWTv3 (a CPU-democratic proof-of-work algorithm), PHANTOM/GhostDAG (high-throughput 1 block-per-second multi-parent DAG ordering), and pure global IPv6 transport (every node possesses a publicly routable global address).

2. Consensus: PHANTOM/GhostDAG (k=18)

Unlike linear blockchains that discard parallel blocks as orphans, Zyanya incorporates all valid blocks into a Directed Acyclic Graph. The GhostDAG algorithm greedily selects a maximal k-cluster of well-connected blocks to establish a robust total order.

SelectedParent(B) = argmax_{P in Parents(B)} (BlueScore(P), BlueWork(P)) BlueScore(B) = BlueScore(SelectedParent(B)) + |Blues(B)|

With parameter k=18, the protocol tolerates extreme block rates (1 BPS) without sacrificing security or re-introducing selfish mining vulnerabilities.

3. Proof-of-Work: AstroBWTv3

AstroBWTv3 is engineered specifically to prevent ASIC and GPU dominance. It utilizes the Burrows-Wheeler Transform over large, dynamic memory buffers with frequent branch mispredictions, maximizing efficiency on modern superscalar general-purpose CPUs.

  • Memory Footprint: 16MB to 64MB dynamic cache allocation per thread.
  • ASIC Resistance: High latency branch divergence minimizes hardware acceleration gains.
  • Democratic Distribution: Anyone with a consumer laptop or desktop CPU can mine with fair probability.

    • 4. Pure IPv6-Only Networking

    Zyanya operates strictly on IPv6. Nodes bind sockets with IPV6_V6ONLY=true, disabling legacy IPv4 fallback.

    Why IPv6 Only? Eliminates NAT hole-punching, STUN/TURN overhead, and centralized relays. Every node is a first-class peer reachable across the global address space.

    5. Zyanya Contract Language (ZCL) & VM

    Smart contracts on Zyanya are compiled to compact bytecode executed by the stack-based ZCL Virtual Machine. Storage slots are indexed by 64-character keys, enabling transparent state queries.

    contract SovereignToken { entry init(supply: u64, slope: u64) { sstore(0, supply); sstore(1, caller()); sstore(2, slope); } entry buy(amount: u64) { let price = sload(2) * amount; require(value() >= price); sstore(0, sload(0) + amount); } }
