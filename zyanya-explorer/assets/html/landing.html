60-Second CPU Mining Quickstart

Zyanya utilizes AstroBWTv3, a memory-hard algorithm specifically optimized for commodity desktop and server CPUs. No ASICs, no cloud mining monopolies.

1. Start Standalone Miner (Windows PowerShell)

Run the miner pointing to your local node (or the testnet sentry at 10.10.1.250:18210):

.\zyanya-miner.exe --testnet -s 10.10.1.250 -p 18210 -t 8 --mining-address <YOUR_ADDRESS>

2. Start Standalone Miner (Linux)

./zyanya-miner --testnet -s 10.10.1.250 -p 18210 -t $(nproc) --mining-address <YOUR_ADDRESS>

3. Generate a New Wallet Address

.\zyanya-wallet.exe new-address
